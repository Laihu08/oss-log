# oss-log

Daily log of my open-source contribution search. Each file under `log/<year>/` is one day's report: how many repositories and issues were scanned, how many candidates were checked, and why they were ruled out.

The search uses local models on my own GPU to rank open issues, then each candidate is checked by hand against the project's contribution rules before any work starts. Issues that are already claimed, already have a PR, or can't be tested properly are skipped rather than rushed.

My merged and open pull requests are listed on my [profile](https://github.com/Laihu08).
